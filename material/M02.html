5 Questions on Coercion

What happens when you combine different data types in a vector?

5.1 What does this return?

c(TRUE, 1)
  1. Characters "TRUE" "1"
  2. Numericals 1 1
  3. Logicals TRUE, TRUE
  4. Numericals 0 1




5.2 What does this return?

c("1", FALSE)
  1. Characters "1" "FALSE"
  2. Numericals 1 0
  3. Logicals TRUE, FALSE
  4. Numericals "FALSE" "FALSE"




5.3 What does this return?

1 + TRUE
  1. Error
  2. 1
  3. 2
  4. TRUE




5.4 What does this return?

1 + "TRUE"
  1. Error
  2. 1
  3. 2
  4. TRUE
